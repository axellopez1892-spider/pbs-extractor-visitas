Extractor de registros de visitas

Sube capturas de “Detalles de actividad” y organiza la información en Excel.

1. Cargar imágenes

Este enlace conecta la herramienta con la hoja de Google Sheets. Se guarda en este navegador.

La fecha y hora de registro se asignan automáticamente al momento de cargar cada imagen en esta herramienta. La ruta y el nombre de la persona se intentan leer del encabezado superior; si no aparece o el reconocimiento falla, puedes completarlos manualmente en la tabla.

Listo para cargar imágenes. Para reconocer texto se necesita conexión a internet la primera vez.

2. Revisar y corregir información

Todos los campos de la tabla se pueden editar antes de exportar o enviar. Se conserva un registro por cada imagen cargada; no se eliminan registros repetidos.

Importante sobre el reconocimiento

El sistema utiliza OCR para leer el texto de las capturas. La calidad, el recorte y el tamaño de letra pueden afectar los resultados. Los datos reconocidos deben revisarse, especialmente números de cuenta, órdenes de trabajo y comentarios. Las imágenes se procesan en el navegador; a Google Sheets se envían los datos extraídos, no las fotografías.
